Acerca de este proyecto

Esta página fue creada como parte de una práctica de programación web.

Objetivos del proyecto

  • Aprender la estructura de HTML.
  • Crear títulos y párrafos.
  • Utilizar enlaces de navegación.
  • Implementar tablas y formularios.

Pasos para crear una página

  1. Crear el archivo index.html.
  2. Escribir la estructura HTML.
  3. Agregar contenido.
  4. Guardar los cambios.
  5. Visualizar la página.
